# SR11-7 Model Risk Management Summary

Issued by the Federal Reserve Board, SR11-7 outlines expectations for institutions to manage and control model risk effectively. Key principles include:

## 1. Model Development and Documentation

- Clearly document model purpose, assumptions, limitations, and inputs.
- Validate underlying data quality and transformations.

## 2. Model Validation

- Conduct independent validation of models before and after deployment.
- Include review of conceptual soundness, performance, and limitations.
- Evaluate model stability over time.

## 3. Ongoing Monitoring

- Regular performance monitoring (accuracy, AUC, drift).
- Re-validation triggered by model updates or performance issues.

## 4. Governance

- Maintain clear governance structure.
- Ensure model inventory and version control.
- Establish validation frequency policies.
